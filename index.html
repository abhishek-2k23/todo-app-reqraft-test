    Task creation docs

    • Title is required and must be at most 120 characters.
    • Description is optional (max 500 characters).
    • Due date is optional. If provided, it must be today or later.
    • On success, a confirmation message is shown and the task appears immediately.
    • Tasks are stored in localStorage so they persist across refreshes.
